# meeting-minutes-v2 安装说明（Windows）

把一场会议的录音，变成**每条结论都能回原文核对**的会议纪要，并输出 Word / 图文摘要 / PPT。

全程本地运行，录音不上传。装好之后可以断网使用。

---

## 一、需要准备什么

| 项目 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10 / 11 | 已在 Windows + Python 3.9.7 实测 |
| Python | **3.10 – 3.12 推荐**（最低 3.9） | 装过 Anaconda / Miniconda 也行 |
| 磁盘 | 首次约 **1 GB**（small 模型）/ 2.5 GB（medium） | 装在用户目录下，可改到别的盘 |
| 内存 | 建议 8 GB 以上 | 4 GB 跑 medium 会很吃力 |
| 网络 | **只有首次安装需要** | 下依赖和模型；之后完全离线 |

---

## 二、五分钟装好（照勾）

> 命令都在 **PowerShell** 里执行。在技能文件夹里按住 Shift + 右键 → "在此处打开 PowerShell 窗口"。

- [ ] **1. 装 Python**（已经装过就跳过）
      官网 <https://www.python.org/downloads/> 下 3.12，安装时**勾上 "Add Python to PATH"**。
      验证：`python --version` 能打印版本号。

- [ ] **2. 解压技能包到固定位置**
      解压出来应该直接看到 `SKILL.md`。建议放在不会随手挪走的地方（例如 `D:\meeting-minutes-v2`）。

- [ ] **3. 体检一下**
      ```powershell
      python scripts\doctor.py
      ```
      它会告诉你缺什么、下一步做什么。**这一步不依赖任何第三方库，环境再干净也能跑。**

- [ ] **4. 装环境（最慢的一步，10–20 分钟）**
      ```powershell
      python scripts\bootstrap.py --install --models small --with-diarization
      ```
      - 会先问一句装到哪个目录，回车用默认（你的用户目录下的 `.meeting-minutes`）
      - C 盘紧张就填别的盘，例如 `D:\AIModels`
      - 装的东西都在那一个目录里，**想卸载直接整个删掉**

- [ ] **5. 再体检一次**
      ```powershell
      python scripts\doctor.py
      ```
      到这一步应该全是 ✅（联网那项如果显示 ⚠️ 不影响使用）。
      记下它打印的 `python = ...`，后面所有命令都用那个解释器。

- [ ] **6. （可选）装成技能，让 AI 自动认得**
      ```powershell
      python scripts\install_skill.py --install
      ```
      之后在对话里说"用 meeting-minutes-v2 把这段录音整理成会议纪要"即可。

- [ ] **7. 试跑 1 分钟验音质**
      ```powershell
      & "<第5步记下的python路径>" scripts\transcribe.py "<你的录音>" --start 60 --duration 60 `
          --out-md "试跑.md"
      ```

## 三、跑一场会议

按技能流程（SKILL.md）会依次做：

1. **开工确认单**：问你会议类型、参会人、说话人数、要什么交付物、闲聊怎么处理
2. **转写**：本地转写 + 说话人分离 + 术语纠错
3. **出纪要**：套模板、挂时间戳锚点
4. **质检**：六项检查 + 锚点对账
5. **交付**：Word / HTML / 图文摘要 / PPT（按需）

产物结构：
```
<会议名>_<日期>\
├── 原文\   转写稿.md / .json / .html
├── 纪要\   会议纪要.docx / .html、图文摘要、待确认清单
└── 过程\   开工确认单、节点记录、质检报告
```

## 四、出问题了怎么办

先跑 `python scripts\doctor.py`，多数问题它会直接告诉你原因和命令。

| 症状 | 原因 | 处理 |
|---|---|---|
| `No module named 'av'` | 用了系统 Python，而不是环境里的那个 | 用 bootstrap 打印的 python 路径 |
| `SSL module is not available` | 某些 conda Python 缺 OpenSSL 路径 | 直接跑 `bootstrap.py`，它会自动修复并重启 |
| pip 装到一半超时 | 网络不稳或镜像被限制 | 重跑一次（会续传）；或换源：`-i https://pypi.org/simple` |
| 模型下不动 | 模型站点被墙 | 见下一节"手动下载模型" |
| 转写很慢 | CPU 算的，正常 | 换 small：`--model small` |
| 说话人编号乱跳 | 人数没给或声纹相似 | 用 `--speakers N` 指定人数 |
| 中文显示乱码 | 用记事本按 GBK 打开了 | 用 VS Code / 浏览器打开，或直接看 `.html` |
| 磁盘不够 | 默认装在 C 盘 | `python scripts\bootstrap.py --home D:\AIModels --install --models small` |
| 装完想卸载 | — | 删掉那个目录（默认 `%USERPROFILE%\.meeting-minutes`）即可，无其它残留 |

### 手动下载模型

下不动模型时，可以手动下载后放到指定位置：

| 模型 | 下载地址 | 放哪里 |
|---|---|---|
| 转写 small | `hf-mirror.com/Systran/faster-whisper-small` 里的 `model.bin`、`config.json`、`tokenizer.json`、`vocabulary.txt` | `<home>\models\faster-whisper-small\` |
| 说话人分割 | `hf-mirror.com/csukuangfj/sherpa-onnx-pyannote-segmentation-3-0` 的 `model.onnx` | `<home>\models\sherpa-segmentation-3.0\model.onnx` |
| 声纹嵌入 | `hf-mirror.com/csukuangfj/speaker-embedding-models` 的 `3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx` | `<home>\models\sherpa-embedding-zh\` |

放好后重跑 `python scripts\doctor.py`，模型那项就会变 ✅。

## 五、没有网络 / 不想装环境怎么办

**完全没网**：依赖和模型都下不来，本技能无法自动安装。两条路：

1. 找同学把已经装好的那个目录（默认 `%USERPROFILE%\.meeting-minutes`）整个拷给你，放到同样位置即可；
2. 只用手工流程：用手机或剪映、飞书之类的字幕功能导出文字稿，再走**单文件版**。

**不想装环境**：用 `单文件版-可直接粘贴给AI.md`——把内容粘进对话，再把转写稿贴给它。
纯文字流程完全一样，只是没有自动转写和自动质检。

## 六、已知限制（这些不是 bug）

| 限制 | 说明 |
|---|---|
| 说话人编号 ≠ 真实身份 | 声纹聚类结果，跨会议不通用；要真名得自己提供名单 |
| 远场/多人抢话录音准确率下降 | 手机放远处录的，专有名词大概率出错，这是物理限制 |
| 质检不能替代人 | Q6 能查出"编造的时间戳"，但措辞是否失真仍需人看一眼 |
| macOS / Linux 未实测 | 脚本是纯 Python，理论上能跑，但没验证过 |
| 首次安装需要联网 | 之后可以完全离线 |

## 七、文件说明

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 主流程（AI 读的就是它） |
| `说明书.md` | 更完整的使用说明与常见问题 |
| `安装说明.md` | 本文件 |
| `单文件版-可直接粘贴给AI.md` | 不装环境时的替代方案（由脚本生成，勿手改） |
| `config.json` | 配置：模型档次、说话人数、阈值等 |
| `术语表.txt` | 通用术语纠错表（可以自己加行，格式 `错的 = 对的`） |
| `references\` | 章节模板、证据与质检规范、交付物格式 |
| `scripts\` | 全部脚本 |
