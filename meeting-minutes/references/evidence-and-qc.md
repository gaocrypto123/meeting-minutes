# 证据字段与质检规范（v2）

## 一、证据字段格式（机器可解析，不得自创）

每条要点 = 一个列表项 + 若干缩进字段，缩进 **2 个空格**，字段名用中文全角冒号。

```markdown
- **决策 D1**：Q3 上线新结算流程，旧流程并行保留 1 个迭代
  - 状态：已决策
  - 责任人：李四
  - 交付物：上线方案 + 回滚预案
  - 截止日：2026-10-15
  - 出处：[00:12:30]、[00:15:02]
  - 引用：「结算这块我建议 Q3 上，老流程先别删，留一个迭代兜底」
```

要点行格式：`- **<类型> <ID>**：<一句话结论>`

- **类型**枚举：`需求` `共识` `决策` `技术要点` `行动项` `方案` `风险` `问题` `进展` `待定事项`
- **ID**：类型首字母 + 序号（如 `决策 D1`、`行动项 A3`、`需求 R2`）

### 出处写法（v2 变更重点）

| 材料形态 | 出处写法 |
|---|---|
| 转写自录音 | `[00:12:30]`，多个用顿号分隔：`[00:12:30]、[00:15:02]` |
| 用户粘贴的文字记录 | `用户提供的文字记录 第3段` |
| 用户口述补充 | `用户口述 2026-09-19 补充` |
| 确实没有依据 | `未找到出处（说明原因）`，同时状态必须写「待确认」 |

**为什么用时间戳而不是行号**：行号会随转写稿重新生成而失效，时间戳指向的是音频本身，永远对得上。`verify_refs.py` 就是拿时间戳去和转写稿 JSON 对账的。

## 二、字段清单

| 字段 | 适用类型 | 必填 | 说明 |
|---|---|---|---|
| 状态 | 全部 | 是 | 见状态枚举 |
| 责任人 | 行动项、方案 | 是 | 未定写「待确认」 |
| 交付物 | 行动项 | 是 | 未定写「待确认」 |
| 截止日 | 行动项 | 是 | 未定写「待确认」，**不得推测日期** |
| 出处 | 除状态=待确认外 | 是 | `[时:分:秒]` |
| 引用 | 建议 | 建议 | 逐字原文，≤50 字，不得改写、不得拼接 |
| 依据 | 决策 | 是 | 决策所依赖的原话或数据出处 |
| 备注 | 可选 | 否 | 对存疑点的说明 |

## 三、状态枚举

| 状态 | 含义 | 可否缺出处 |
|---|---|---|
| 已确认 | 会上明确同意 | 否 |
| 已决策 | 会上拍板定案 | 否 |
| 待确认 | 会上没定 / 听不清 / 找不到依据 | 是（写「未找到出处」并说明） |
| 已否决 | 会上明确否定 | 否 |
| 已延期 | 明确推迟到下次 | 否 |

「待确认」只表示"会上确实没定"，**不表示"我猜是这样但不确定"**——猜出来的一律删除。

## 四、质检六项（Phase 4）

质检只管查，不管补。

| 编号 | 检查项 | 判定方法 | 不通过条件 |
|---|---|---|---|
| Q1 | 可回溯性 | 条件条目是否都有「出处」字段 | 状态≠待确认 且 出处缺失 |
| Q2 | 章节完整性 | 对照 templates.md 的类型模板 | 模板章节标题缺失 |
| Q3 | 行动项三要素 | 责任人 / 交付物 / 截止日 | 任一字段整体缺失（写「待确认」算通过） |
| Q4 | 无凭空内容 | 正文里的日期、数量回原文比对 | 任一数字在原文查无来源 |
| Q5 | 去重 | 同类条目标题归一化比对 | 同一事项在多处重复 |
| **Q6** | **出处可验证** | **用 `verify_refs.py` 把锚点和转写稿 JSON 对账** | **任一时间戳在转写稿中找不到对应发言** |

Q6 是 v2 新增，也是最重要的一项：**它把"出处"从一句声明变成了一个可被机器验证的事实**。

## 五、修复动作白名单（R8）

只允许两个动作：

1. 把内容或字段标注为「待确认」
2. 删除该条目

禁止：补写原文没有的内容、把数字改成"看起来更合理"的数字、为了让 Q3 通过而编个截止日、**为了让 Q6 通过而编个时间戳**。

## 六、待确认清单格式

按影响排序，分三段：必须优先确认 / 待补信息 / 转写质量说明。

```markdown
| # | 事项 | 类型 | 存疑点 | 建议确认对象 | 影响 |
|---|---|---|---|---|---|
| 1 | 任务原句「参照视力内容…」 | 事实 | 疑为「事例」 | 老师 | 理解错等于全篇返工 |
```

## 七、非议题内容（v2 新增）

用户选择"保留标记"时，寒暄、闲聊、用餐、转写噪声区间统一收进纪要的
`## 附录 · 非议题内容（保留备查）`，用表格列出区间、时长、内容与处理方式。

- 只在附录出现，**不进正文、不作为任何结论的依据**
- 噪声区间要显式标注「不可信，不得引用」
- 附录章不参与 Q2 的模板校验
